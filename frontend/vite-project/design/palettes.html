Palette options

Seventeen directions in three groups: 1–5 monochrome, 6–10 one signature colour, 11–17 multi-colour systems. Each is shown in light and dark, with a swatch strip and a realistic slice of the app.

Pick one by number — e.g. “use palette 12”. You can also mix: “palette 2, but the primary button from 9”. I’ll then write the chosen values into src/index.css.

About your colours: the source hex is marked source in each swatch strip. A single hex can’t fill every role at accessible contrast, so where small text needs 4.5:1 the palette uses a deepened shade of the same hue, and dark mode uses a lightened one. The source colour still carries the identity — fills, checkboxes, brand dot, focus ring.

All 17 are contrast-checked (WCAG AA 4.5:1 for text, 3:1 for graphical marks) in both themes.

Note: error/danger keeps a restrained red in every option so mistakes stay recognizable (color shouldn’t be the only signal). Say the word if you want danger fully grayscale too.
